# data/

Everything in this folder except this file is generated by `CNN/prepare_data.py`
(the `prepare_data` CMake target) and ignored by git. Run it once; it skips what
is already present.

```
data/
├── _downloads/          # Raw archives and extracted originals, kept so re-runs don't download again
├── train/HR/            # 291 training images: t91_*.png (T91) + bsd200_*.png (BSDS300 train split)
└── test/<Set>/          # Set5, Set14, BSD100, Urban100
    ├── HR/              # Ground truth, mod-cropped to a multiple of 4, PNG
    ├── LR_x2/           # HR bicubic-downscaled by 2 (Pillow, antialiased), same file names as HR/
    └── LR_x4/           # HR bicubic-downscaled by 4, same file names as HR/
```

The benchmark pairs `LR_x<scale>/<name>.png` with `HR/<name>.png`. Any extra folder
under `test/` with this layout is picked up automatically.
